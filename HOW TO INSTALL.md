BLUEPRINT

------------------------------------------------------------------------------------------------------------------
[Fr] - BluePrint est un script InDesign permettant de créer toutes sortes d'impositions dans différents calques.
------------------------------------------------------------------------------------------------------------------
//INSTALLATION//

  1• TÉLÉCHARGER le fichier .jsx
  
  2• DÉPLACER le fichier dans:
 
`MacOS`         ```/Applications/Adobe InDesign 20XX/Scripts/Script Panels```

`Windows`      ```C:/Program Files/Adobe/Adobe InDesign 20XX/Script/ Script Panels``` 

  ATTENTION. 20XX DOIT ÊTRE L'ANNÉE DE VOTRE INDESIGN.

//UTILISATION//

  1• SELECTIONNER le panneau SCRIPT dans FENETRE -> UTILITAIRE -> SCRIPT

  2• Dans le PANNEAU SCRIPT dérouler APPLICATION

  3• DOUBLE CLIQUER sur BLUEPRINT.JSX

A VOUS DE JOUER !


------------------------------------------------------------------------------------------------------------------
[En] - BluePrint is an InDesign script that allows you to create all kinds of impositions across different layers.
------------------------------------------------------------------------------------------------------------------
//INSTALLATION//

1• DOWNLOAD the .jsx file

2• MOVE the file to:

`MacOS`         `/Applications/Adobe InDesign 20XX/Scripts/Script Panels`

`Windows`       `C:/Program Files/Adobe/Adobe InDesign 20XX/Script/Script Panels`

PLEASE NOTE: 20XX MUST MATCH THE YEAR OF YOUR INDESIGN VERSION.

//USAGE//

1• SELECT the Scripts panel under Window → Utilities → Scripts

2• In the Scripts panel, expand Application

3• DOUBLE-CLICK on BLUEPRINT.JSX

NOW IT’S YOUR TURN!
